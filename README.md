# Proyecto: Análisis de Datos Climáticos

## Integrantes

* Elias Ceballos

## Escenario elegido

Escenario A - Análisis de Datos Climáticos

## Descripción del proyecto

Este proyecto consiste en desarrollar un script en Python que permita
trabajar con datos meteorológicos históricos obtenidos desde un archivo CSV.

A partir de estos datos se realizará un análisis básico de temperaturas
y precipitaciones, obteniendo distintos indicadores y generando gráficos
para visualizar la información de manera más clara.

## Objetivos

* Analizar datos climáticos históricos.
* Obtener indicadores básicos de temperatura y precipitaciones.
* Representar visualmente la evolución de la temperatura en el tiempo.

## Tareas realizadas

* Importación de datos desde un archivo CSV.
* Procesamiento y análisis de la información climática.
* Cálculo de:

  * temperatura promedio
  * temperatura máxima
  * temperatura mínima
  * promedio de precipitaciones
* Generación de gráficos.
* Guardado automático de resultados en la carpeta `/resultados`.
